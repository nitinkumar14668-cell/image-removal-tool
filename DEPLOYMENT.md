# 🚀 Deployment Guide\n\n## Vercel Deployment (Frontend)\n\n### Step 1: Prepare Your Repository\n\n```bash\n# Initialize git if not already done\ngit init\ngit add .\ngit commit -m \"Initial commit: Image Removal Tool\"\ngit branch -M main\ngit remote add origin https://github.com/yourusername/image-removal-tool.git\ngit push -u origin main\n```\n\n### Step 2: Deploy Frontend to Vercel\n\n1. Go to [Vercel](https://vercel.com)\n2. Click **\"New Project\"**\n3. Import your GitHub repository\n4. Select **\"Next.js\"** framework\n5. Configure settings:\n   - **Root Directory**: `frontend` ✓\n   - **Build Command**: `npm run build`\n   - **Output Directory**: `.next`\n\n6. Add Environment Variables:\n   ```\n   NEXT_PUBLIC_BACKEND_URL=https://your-backend-domain.com\n   ```\n\n7. Click **\"Deploy\"**\n\n### Step 3: Backend Deployment Options\n\n#### Option A: Railway (Recommended for Beginners)\n\n```bash\n# 1. Install Railway CLI\n# Visit: https://railway.app\n\n# 2. Login and initialize\nrailway login\nrailway init\n\n# 3. Add backend environment variables\nrailway variables set FLASK_ENV=production\nrailway variables set FLASK_DEBUG=False\n\n# 4. Deploy\nrailway up\n```\n\n#### Option B: Render\n\n1. Go to [Render](https://render.com)\n2. Click **\"New\" → \"Web Service\"**\n3. Connect your GitHub repository\n4. Configure:\n   - **Root Directory**: `backend`\n   - **Build Command**: `pip install -r requirements.txt`\n   - **Start Command**: `gunicorn app:app`\n\n5. Add Environment Variables:\n   ```\n   FLASK_ENV=production\n   FLASK_DEBUG=False\n   ```\n\n6. Deploy\n\n#### Option C: Google Cloud Run\n\n```bash\n# 1. Install Google Cloud SDK\n# Visit: https://cloud.google.com/sdk\n\n# 2. Authenticate\ngcloud auth login\n\n# 3. Set project\ngcloud config set project YOUR_PROJECT_ID\n\n# 4. Build and deploy\ncd backend\ngcloud run deploy image-removal-api \\\n  --source . \\\n  --platform managed \\\n  --region us-central1 \\\n  --allow-unauthenticated\n```\n\n#### Option D: Heroku (Deprecated but still works)\n\n```bash\n# 1. Install Heroku CLI\n# Visit: https://devcenter.heroku.com/articles/heroku-cli\n\n# 2. Login\nheroku login\n\n# 3. Create app\nheroku create your-app-name\n\n# 4. Add Procfile\necho \"web: cd backend && gunicorn app:app\" > Procfile\n\n# 5. Deploy\ngit push heroku main\n```\n\n### Step 4: Update Frontend with Backend URL\n\nAfter backend deployment, update Vercel environment variable:\n\n```\nNEXT_PUBLIC_BACKEND_URL=https://your-backend-domain.com\n```\n\nThen redeploy frontend on Vercel.\n\n## 🔧 Fix 404 Errors\n\n### Issue 1: Frontend Routes Not Found\n\n**Solution**: Update `frontend/next.config.js`\n\n```javascript\nconst nextConfig = {\n  async rewrites() {\n    return {\n      beforeFiles: [\n        { source: '/api/:path*', destination: '/api/:path*' },\n      ],\n    };\n  },\n};\n```\n\n### Issue 2: API Routes Not Working\n\n**Solution**: Check API routes are in correct location:\n\n```\nfrontend/app/api/\n  ├── remove/route.ts\n  ├── batch/route.ts\n  └── adjust/route.ts\n```\n\n### Issue 3: Backend URL Not Set\n\n**Solution**: Verify environment variables in Vercel dashboard:\n\n1. Go to Vercel Project Settings\n2. Click **\"Environment Variables\"**\n3. Add: `NEXT_PUBLIC_BACKEND_URL=https://your-api.com`\n4. Redeploy\n\n### Issue 4: CORS Errors\n\n**Solution**: Update backend `app.py`:\n\n```python\nfrom flask_cors import CORS\n\napp = Flask(__name__)\nCORS(app, resources={\n    r\"/api/*\": {\n        \"origins\": [\"https://your-vercel-domain.com\"],\n        \"methods\": [\"GET\", \"POST\", \"OPTIONS\"],\n        \"allow_headers\": [\"Content-Type\"]\n    }\n})\n```\n\n## 📊 Monitoring\n\n### Vercel\n- Dashboard: https://vercel.com/dashboard\n- Logs: Project → Deployments → Click deployment → Logs\n\n### Backend (Railway/Render)\n- Check deployment logs for errors\n- Monitor resource usage\n\n## 🔒 Security Checklist\n\n- [ ] Set `FLASK_DEBUG=False` in production\n- [ ] Use environment variables for sensitive data\n- [ ] Enable HTTPS (automatic on Vercel, Railway, Render)\n- [ ] Set proper CORS origins\n- [ ] Validate all inputs\n- [ ] Rate limiting on API endpoints\n\n## 📈 Performance Optimization\n\n1. **Frontend**:\n   ```bash\n   npm run build\n   # Check: .next/static file size\n   ```\n\n2. **Backend**:\n   -
